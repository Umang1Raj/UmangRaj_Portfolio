# Umang Raj — Portfolio

An interactive, cutting-edge 3D student portfolio and CV website built for **Umang Raj**, an Artificial Intelligence and Machine Learning student at Acharya Institute of Technology, Greater Bengaluru.

## Highlights & Features

1. **Interactive 3D WebGL Scene**:
   - **Central Quantum AI Core**: Pulsing glowing plasma core, rotating wireframe icosahedron, three gyro orbital rings (neon lime, cyan, orange), and orbiting data crystals.
   - **Neural Particle Constellation**: 1,100+ ambient reactive particles drifting dynamically in 3D coordinate space.
   - **Scroll-Driven Cinematic Camera**: Smooth camera waypoint interpolation that navigates through 3D space as you scroll through portfolio sections.
   - **Interactive Core Pulse**: Engage the AI Core via the hero CTA to emit a resonance wave through the 3D structures.

2. **3D Tilt & Glassmorphism UI**:
   - Gyro-tilt physics on certificate cards, profile dossier, GitHub showcase, skills, and contact channels with dynamic specular glare reflection.

3. **Verified Certificate Inspection Modal**:
   - High-definition image previews of all completed certificates:
     - *Learning Python* (LinkedIn Learning · Jul 2026)
     - *Python* (Kaggle Learn · Jul 2026)
     - *Introduction to Modern AI* (Cisco Networking Academy · Feb 2026)
   - Direct verification links to Credly, LinkedIn, and Kaggle.

4. **Public Neural Lab & Cyber Terminal**:
   - Interactive terminal HUD featuring the `Umang1Raj/Learn` repository.
   - "Simulate Run ⚡" interactive command test simulation with live terminal log output.

5. **Built-in Web Audio Synthesizer**:
   - Zero external audio files; pure Web Audio API synthesizer for tactile UI sound effects (blips, confirmation chords, modal whooshes). Toggleable anytime from the top HUD.

6. **Full CV Integration**:
   - Interactive 3D CV preview modal.
   - Dedicated print-ready `cv.html` for clean Save-as-PDF export.

## How to View

Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari) or serve with any local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Or using npx serve
npx serve .
```
